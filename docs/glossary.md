# Ecosystem glossary

## Agent WebUI

The operator experience for working with agents and their runtime.

## GraphOS

The public runtime gateway for client access, identity, routing, and runtime policy.

## agent-utilities

The agent control plane for orchestration, workflows, evaluation, and agent skills.

## epistemic-graph

The durable multimodal knowledge and reasoning engine for graph data, evidence, and provenance.

## agent-connector-sdk

The governed source integration boundary for discovering, reading, and synchronizing external systems.

## MCP

The Model Context Protocol, a standard interface for exposing tools and context to AI applications.

## A2A

Agent-to-Agent, a protocol for communication and task exchange between agents.

## OWL

The Web Ontology Language, used to define classes, properties, and logical relationships.

## RDF

The Resource Description Framework, a graph data model for describing resources and their relationships.

## SHACL

The Shapes Constraint Language, used to validate graph data against declared shapes.

## UQL

Unified Query Language, the graph query surface used by the ecosystem.
