# EG-SCM requirements

| ID | Requirement | Verification |
|---|---|---|
| `EG-SCM-R001` | **Content-addressed blob store.** Model: each file version is a sealed blob record. The record is keyed by its SHA-256 digest. Identical bytes store once. The blob is compressed. A read takes a digest and returns the bytes. Behavior: a second write of the same bytes returns the same digest. It adds no new storage. A changeset path points to a blob by digest only. Wiring: compose the existing content-addressed chunk store (`src/server/blob/store.rs`) and its bounded streaming facade (`src/server/blob/stream.rs`). Reuse the sealed create-only record guard of EG-DURABLE-KERNEL-R057. Refusal: the store refuses an overwrite of an existing digest. It refuses an unreadable digest with a typed error. Evidence: identical bytes return one digest. A digest readback equals the original bytes. | `tests/test_scm_blob.py::test_blob_stored_once_and_read_by_digest` stores two identical versions. It reads the blob back by digest. |
| `EG-SCM-R002` | **Changeset record.** Model: a changeset is `Changeset{id, repo, parents, author_principal, message, changed_paths, created_at, gate_verdicts}`. `changed_paths` is a list of `{path, op, old_blob, new_blob, mode}`. The op is add, modify, delete, or rename. The record stores only the paths that changed against the first parent. It costs O(change), never O(repository). Behavior: an append to a branch chain adds one record. A changeset with a parent names the parent head. The append is atomic with the branch head advance. Wiring: add the record type to `crates/eg-types` as `source_changeset.rs`. Append through the branch commit path of EG-BRANCH-MERGE-R002. Refusal: the engine refuses a changeset with an empty path list. It refuses a parent not on the target branch chain. It refuses a digest the blob store cannot read. Every refusal leaves the chain unchanged. Evidence: a two-path changeset stores exactly two path entries. The chain readback returns the record unchanged. | `tests/test_scm_changeset.py::test_changeset_stores_only_changed_paths` writes a three-file repository state. It changes two files. It asserts one changeset with two path entries. |
| `EG-SCM-R003` | **Lock-free acceptance.** Model: concurrent changesets on one branch are judged by their path sets. Disjoint path sets are accepted in parallel. Overlapping path sets trigger a server-side decision. Behavior: two writers on disjoint paths both land. No global lock gates either write. On overlap, the server rebases the late changeset on the new head. The rebase uses a file-level three-way merge at line granularity. It reuses the merge pass of EG-BRANCH-MERGE-R004. A clean rebase lands as the new head. An unclean overlap is refused with the stable `SOURCE_CONFLICT{paths}` code. The refusal lists every conflicting path. Wiring: compose the version-checked write path of EG-DURABLE-KERNEL-R084. Reuse the branch chain append of EG-BRANCH-MERGE-R002. Refusal: the engine refuses a changeset whose base left the branch chain. The refusal names the stale base. It never rebases silently. Evidence: two disjoint writers both land. Two overlapping writers land one and conflict the other. | `tests/test_scm_accept.py::test_disjoint_writers_land_and_overlap_rebases_or_conflicts` drives two concurrent writers on disjoint paths. It drives two on one shared path. It asserts one landing plus one typed conflict. |
| `EG-SCM-R004` | **Tree materialization by query.** Model: a tree is `Tree(repo, rev, prefix, depth)`. It returns entries of `{path, blob_digest, mode}`. The tree is computed from the changeset chain. Periodic snapshot checkpoints bound the replay length. Behavior: a subtree read at any revision returns the entries at that revision. The read costs O(subtree), never O(history). A prefix read returns only that prefix. A depth bound limits the walk. Wiring: add the tree query to `crates/eg-compute` as `source_tree.rs`. Reuse the snapshot checkpoint path of EG-DURABLE-KERNEL-R023. Refusal: the engine refuses a revision not on the repository chain. It refuses a cross-tenant tree read. Both refusals are typed. Evidence: a tree read at revision N equals the full replay of changesets up to N. The checkpoint path returns the same entries. | `tests/test_scm_tree.py::test_tree_at_revision_matches_full_replay` builds a ten-revision chain. It reads a subtree at each revision. It asserts equality against a full replay. |
| `EG-SCM-R005` | **Derived history indexes.** Model: four derived indexes serve history. Path history lists the changesets that touched a path. Blame maps each line to its last changeset. Ancestry skip lists accelerate merge-base and ancestor queries. Change coupling pairs files that change together. Behavior: each index updates incrementally as changesets land. A revision replay appends and never rewrites. Every index carries a version and a rebuild recipe. A rebuild from the changeset chain reproduces the index byte-for-byte. Wiring: add `crates/eg-compute/src/source_history.rs`. Reuse the incremental derived-series machinery of EG-REPO-INGEST-R004. Reuse the commit and change-coupling graph of EG-REPO-INGEST-R601. Refusal: the engine refuses an index read at a version past the index head. It refuses a cross-tenant history read. Evidence: incremental index state equals a from-scratch rebuild. A rebuild after corruption restores identical entries. | `tests/test_scm_history.py::test_incremental_indexes_equal_rebuild` applies a changeset sequence incrementally. It rebuilds the same indexes from scratch. It asserts byte-identical output. |
| `EG-SCM-R006` | **Code graph stays live with changesets.** Model: an accepted changeset is an input to the code graph. Only structurally changed files re-enter the pipeline. Behavior: the engine re-parses each structurally changed file. It updates fingerprints per EG-REPO-INGEST-R603. It updates symbols and tests per EG-REPO-INGEST-R600. It recomputes Leiden communities per EG-REPO-INGEST-R011. The community pass runs on the affected subgraph only. `code_context` and UQL answer from the new state as soon as the changeset lands. Wiring: attach to the incremental indexing boundary of EG-REPO-INGEST-R006.4. Reuse the existing enrichment and community-detector callers. Refusal: the engine refuses an indexing job whose base revision does not match. It follows the existing incremental-index refusal. Evidence: a one-file change updates only that file symbols. A structural no-op change updates nothing. | `tests/test_scm_code_graph.py::test_one_file_change_updates_only_its_symbols` lands a one-file changeset. It asserts the symbol graph updates for that file only. |
| `EG-SCM-R007` | **Path-scoped access control.** Model: a permission binds a path prefix, a principal, and a tenant. The permission carries separate read and write bits. Behavior: a read resolves the most specific prefix grant. A write requires a write grant on the path. The grant applies to tree, blob, changeset, and derived-index reads alike. Wiring: extend the universal read-RLS gate of EG-DURABLE-KERNEL-R029 with a path-prefix predicate. Reuse the existing tenant and principal resolution. Refusal: the engine refuses a read under a prefix with no read grant. It refuses a write with no write grant. It refuses a grant on a path outside the tenant scope. Evidence: a prefix grant filters reads to the prefix. A write outside the prefix is refused with a typed code. | `tests/test_scm_path_access.py::test_prefix_grant_filters_reads_and_refuses_writes` grants a prefix to one principal. It reads inside and outside the prefix. It attempts a write outside the prefix. |
| `EG-SCM-R008` | **Gate verdicts are records.** Model: a gate run records a verdict against a changeset. The record is `GateVerdict{changeset, gate_id, input_digest, verdict, evidence_digest, duration}`. The input digest binds the exact tree the gate read. Behavior: a landing policy reads the verdicts before it lands a changeset. A failed verdict blocks the landing. A verdict is sealed once written. Wiring: reuse the typed verdict model of EG-DURABLE-KERNEL-R089.1. Store the verdict under the sealed create-only guard of EG-DURABLE-KERNEL-R057. Refusal: the engine refuses a verdict whose input digest does not match the changeset tree. It refuses an overwrite of a sealed verdict. Evidence: verdict records read back byte-identically. A mismatched digest is refused. | `tests/test_scm_gate_verdict.py::test_verdict_records_are_sealed_and_read_back` records a pass verdict and a fail verdict. It reads both back. It attempts an overwrite and asserts the refusal. |
| `EG-SCM-R009` | **Bisect and revert decisions.** Model: a failed post-landing gate opens a bisect. The bisect walks the changeset chain from the failure back to the last good verdict. It uses recorded verdicts and on-demand gate runs. Behavior: the bisect identifies the culprit changeset. The engine then records a decision. The decision is a changeset revert or a fix-forward task. The decision record carries the evidence that produced it. Wiring: reuse the deterministic replay of committed decision records (EG-DECISION-ENGINE-R007). Store the decision with the existing decision-record authority. Refusal: the engine refuses a bisect whose chain lacks verdict coverage. It refuses a revert that later changesets depend on. Evidence: a bisect over a seeded chain names the seeded culprit. The recorded decision replays byte-identically. | `tests/test_scm_bisect.py::test_bisect_finds_culprit_and_replays_decision` seeds a failing change mid-chain. It bisects. It replays the recorded decision. |
| `EG-SCM-R010` | **Git import and export fidelity.** Model: a changeset maps one-to-one to a git commit. The export re-creates the commit with the same tree hash. An external git commit imports as a changeset. Behavior: an export of the full chain produces a git history. The history matches the changeset order and messages. A git import of that history reproduces the changeset chain. The round trip is lossless on commit ids and tree ids. Wiring: add `crates/eg-compute/src/source_git_objects.rs`. It builds git objects from the tree entries. Refusal: the engine refuses an export whose tree read fails mid-stream. It refuses an import whose commit graph is malformed. Evidence: export then import preserves every commit id and tree id. | `tests/test_scm_git_round_trip.py::test_export_import_preserves_commit_and_tree_ids` exports a chain of twenty changesets. It imports the archive. It asserts identical commit and tree ids. |
| `EG-SCM-R011` | **Simulation harness.** Model: a hermetic simulation drives the accept path under stress. The simulation owns its clock and its failure injection. Behavior: the harness simulates concurrent writers with overlapping paths. It simulates a server rebase on a dirty base. It simulates a crash mid-accept and a full replay. It simulates export round trips at random intervals. It fuzzes changeset sequences against the same invariants. Wiring: add `tests/simulation/source_changesets.rs`. Drive the real accept, rebase, and tree paths. Refusal: the harness refuses a fuzz seed that fails to seed. A refused seed records no state. Evidence: every invariant holds across the full simulation matrix. A seeded regression fails the harness. | `tests/simulation/source_changesets.rs::simulate_concurrent_accept_crash_and_replay` drives concurrent accepts with crash and replay. It asserts chain invariants after every step. |
| `EG-SCM-R012` | **Agent-only principals and run provenance.** Model: an agent principal binds to a run. The binding is the RunTrace id of the run that produced the changeset. The changeset also records the agent identity. Behavior: an agent changeset carries both ids on acceptance. A human principal may omit the run trace id. The record is queryable by run, by agent, and by changeset. Wiring: attach to the changeset accept path of EG-SCM-R002. Reuse the RunTrace record authority already served by the engine. Refusal: the engine refuses an agent changeset with no run trace id. The refusal is typed. Evidence: an agent changeset reads back with its run trace id. A principal without a run id is refused. | `tests/test_scm_provenance.py::test_changeset_links_to_run_trace` submits an agent changeset with a run trace id. It reads the binding back. It submits one without and asserts the refusal. |
