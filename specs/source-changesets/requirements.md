# MEDULLA-SCM requirements

| ID | Requirement | Verification |
|---|---|---|
| `MEDULLA-SCM-R001` | **Content-addressed blob store.** Stage: served method `SubmitChangeset`, blob phase. Each file version is a blob keyed by its SHA-256 digest. Identical bytes store once. Caller: `Method::SubmitChangeset` → `src/server/handlers/source_changeset.rs::accept_blobs` → `stream_blob_put` at `src/server/blob/stream.rs:35`, which writes through the chunk store `src/server/blob/store.rs`. A read calls `stream_blob_get` at `stream.rs:90` by digest. A second write of the same bytes returns the same digest and adds no storage. Limit: `SchedulerConfig.changeset_max_blob_bytes` default 134217728, range [1048576, 4294967296], unit bytes. The record class is sealed and create-only (`MEDULLA-DURABLE-KERNEL-R057`). Refusals: `BLOB_DIGEST_MISMATCH` when declared and computed digests differ, `BLOB_TOO_LARGE`, `BLOB_NOT_FOUND` for an unreadable digest. Depends on: none. | Test: `tests/test_scm_blob.py::test_blob_stored_once_and_read_by_digest` (L3). It stores two identical versions through `SubmitChangeset`. It reads the blob back by digest. It asserts one stored copy and each refusal. |
| `MEDULLA-SCM-R002` | **Changeset record.** Stage: served method `SubmitChangeset`. `Changeset` in `crates/medulla-types/src/source_changeset.rs` has `id`, `repo`, `parents`, `author_principal`, `message`, `changed_paths`, `created_at`, `trailers`. Add `agent_identity: Option<String>` and `run_trace_id: Option<String>` (`R012`). Remove the planned `gate_verdicts` field: verdicts are sealed records that name the changeset (`R008`). `id` is the SHA-256 of the canonical record. `changed_paths` holds `{path, op, old_blob, new_blob, mode}` against the first parent only, so cost is O(change). The changeset chain is the branch commit chain of `MEDULLA-BRANCH-MERGE-R002`. This row owns the record content only. New `Method::SubmitChangeset{repo, branch, base_head, message, paths, trailers, run_trace_id}` goes beside `SourceIngestStatus` in `crates/medulla-types/src/protocol/method/method_10.rs`. Handler: new `src/server/handlers/source_changeset.rs::accept`. It appends through the branch commit path, atomic with the head advance. Refusals: `CHANGESET_EMPTY`, `CHANGESET_PARENT_NOT_ON_BRANCH`, `BLOB_NOT_FOUND`. Every refusal leaves the chain unchanged. Depends on: `MEDULLA-BRANCH-MERGE-R002`, `MEDULLA-SCM-R001`. | Test: `tests/test_scm_changeset.py::test_changeset_stores_only_changed_paths` (L3). It writes a three-file repository, changes two files and asserts one changeset with two path entries and the three refusals. |
| `MEDULLA-SCM-R002.1` | **Structured trailers on a changeset.** Stage: git import and `SubmitChangeset`. `Trailers{spec_ids, fixes, withdraw, withdraw_reason}` exists in `crates/medulla-types/src/source_changeset.rs`. `Trailers::parse` reads the `Spec:`, `Fixes:` and `Spec-Withdraw:` lines of the last message paragraph. `Trailers::render` writes them back in that order. Caller: `Method::ImportGitHistory` (`R010`) → `source_git_objects.rs::import_commit` → `Trailers::parse`; export calls `Trailers::render`. `Method::SubmitChangeset` parses the message when `trailers` is absent. `MEDULLA-SDLC-R001.2` and `MEDULLA-SDLC-R005` read the typed fields. Depends on: `MEDULLA-SCM-R010`. | Test: `tests/test_scm_changeset.py::test_trailers_round_trip_through_git` (L3). It imports a commit with three trailer kinds and exports an identical commit id. |
| `MEDULLA-SCM-R003` | **Path-set acceptance and rebase.** Stage: served method `SubmitChangeset`, accept phase. Disjoint path sets land in parallel with no global lock, by the version-checked write of `MEDULLA-DURABLE-KERNEL-R084`. The generalized rule is `MEDULLA-ENGINE-PARITY-R004`. Its row `MEDULLA-ENGINE-PARITY-R004.2` provides the disjoint check, and this row consumes it. Caller: `source_changeset.rs::accept` compares the path set of the submission with the changesets after `base_head`. On overlap it calls `merge_lines(base_blob, ours_blob, theirs_blob)` (`MEDULLA-BRANCH-MERGE-R008`) per overlapping path. A clean rebase lands as the new head. An unclean overlap refuses with `SOURCE_CONFLICT{paths}` and lists every conflicting path. A base that left the branch chain refuses with `CHANGESET_BASE_STALE` and names it. The engine never rebases silently. Depends on: `MEDULLA-SCM-R002`, `MEDULLA-ENGINE-PARITY-R004.2`. | Test: `tests/test_scm_accept.py::test_disjoint_writers_land_and_overlap_rebases_or_conflicts` (L3). It drives two concurrent writers on disjoint paths and two on one path. It asserts two landings, then one landing plus one typed conflict. |
| `MEDULLA-SCM-R003.1` | **Path-set acceptance calls the shared disjoint check.** Stage: source changeset acceptance. Caller: served changeset accept → path-set acceptance in `MEDULLA-SCM-R003` → `medulla_transaction::occ::disjoint`. Two changesets whose `TxnFootprint` write sets share no path range both land with no branch-wide lock. An overlap enters the three-way merge of `MEDULLA-BRANCH-MERGE-R004`. Provider: `MEDULLA-ENGINE-PARITY-R004.2`. Depends on: `MEDULLA-ENGINE-PARITY-R002.1`. | Test: `tests/test_scm_disjoint_served.py::test_disjoint_changesets_land_in_parallel` (L4) submits two disjoint changesets and asserts both land. |
| `MEDULLA-SCM-R004` | **Tree materialization by query.** Stage: served method `ReadTree{repo, rev, prefix, depth}`, new beside `SubmitChangeset` in `method_10.rs`. It returns entries `{path, blob_digest, mode}`. New `crates/medulla-compute/src/source_tree.rs::tree_at(chain, rev, prefix, depth)` replays the chain from the nearest checkpoint. A checkpoint is a stored full tree snapshot written every `SchedulerConfig.tree_checkpoint_interval` changesets, default 1000, range [10, 100000]. A subtree read costs O(subtree). A prefix read returns only that prefix. `depth` 0 means unbounded and the maximum is 64 (`Fixed`). Handler: `src/server/handlers/source_tree.rs::read_tree`. Refusals: `REVISION_NOT_ON_CHAIN`; the existing request-boundary tenant refusal for a cross-tenant read. Depends on: `MEDULLA-SCM-R002`. | Test: `tests/test_scm_tree.py::test_tree_at_revision_matches_full_replay` (L3). It builds a ten-revision chain and reads a subtree at each revision. It asserts equality with a full replay, with and without a checkpoint. |
| `MEDULLA-SCM-R005` | **Derived history indexes (rollup).** Stage: derived indexes updated by `SubmitChangeset`. Three indexes serve history. They are path history, blame and ancestry skip lists. Change coupling is owned by `MEDULLA-REPO-INGEST-R601` and is not rebuilt here. Each index updates incrementally in `crates/medulla-compute/src/source_history.rs::apply_changeset`, which `source_changeset.rs::accept` calls after each append. Each carries a version number and a rebuild recipe. A rebuild from the chain reproduces the index byte for byte. Refusal: `HISTORY_VERSION_AHEAD` for a read past the index head. Cross-tenant reads use the request-boundary refusal. Children `.1` to `.3` deliver the three indexes. Depends on: `MEDULLA-SCM-R002`. | Test: `tests/test_scm_history.py::test_incremental_indexes_equal_rebuild` (L3). It applies a changeset sequence incrementally, rebuilds from scratch and asserts byte-identical output. |
| `MEDULLA-SCM-R005.1` | **Path history.** Method `ReadPathHistory{repo, path, rev, limit}` lists the changesets that touched `path`, newest first. The index maps `path` to an ordered list of changeset ids. `limit` default 100, maximum 1000 (`Fixed`). Handler: `source_history.rs::path_history`. Depends on: `MEDULLA-SCM-R005`. | Test: `tests/test_scm_history.py::test_path_history_lists_touching_changesets` (L3). |
| `MEDULLA-SCM-R005.2` | **Blame.** Method `ReadBlame{repo, rev, path}` maps each line to its last changeset. The index stores per-path line origin vectors, updated by a line diff against the parent blob. Renames carry the vector to the new path. Handler: `source_history.rs::blame`. Binary blobs refuse with `BLAME_BINARY`. Depends on: `MEDULLA-SCM-R005`. | Test: `tests/test_scm_history.py::test_blame_attributes_lines_across_rename` (L3). |
| `MEDULLA-SCM-R005.3` | **Ancestry skip lists.** Each changeset stores skip pointers to its ancestors at distances 1, 2, 4 up to 65536. `merge_base` and `is_ancestor` walk the pointers in O(log n). `MEDULLA-BRANCH-MERGE-R003` calls `merge_base`. Handler: `source_history.rs::merge_base`. Depends on: `MEDULLA-SCM-R005`. | Test: `crates/medulla-compute/tests/source_history.rs::skip_lists_find_merge_base_in_log_steps` (L2). |
| `MEDULLA-SCM-R006` | **Code graph stays live with changesets.** Stage: `SubmitChangeset`, post-accept. Only structurally changed files re-enter the pipeline. Caller: `source_changeset.rs::accept` → new `reindex_changeset(changeset)` in `src/server/handlers/repository_index/enrich.rs`. For each changed path it calls `fingerprint` and `classify` (`MEDULLA-REPO-INGEST-R603.3`). For each structural change it parses the file and updates symbols and tests (`MEDULLA-REPO-INGEST-R600.3`). It recomputes communities on the affected subgraph only (`MEDULLA-REPO-INGEST-R011`). `code_context` and UQL read the new state as soon as the changeset lands. Refusal: `INDEX_BASE_MISMATCH` (`MEDULLA-REPO-INGEST-R006.4`). Then `MEDULLA-SDLC-R001.3` derives lifecycle edges. Depends on: `MEDULLA-REPO-INGEST-R600.3`, `MEDULLA-REPO-INGEST-R603.3`, `MEDULLA-SCM-R003`. | Test: `tests/test_scm_code_graph.py::test_one_file_change_updates_only_its_symbols` (L3). It lands a one-file changeset and asserts the symbol graph changes for that file only. A cosmetic change updates nothing. |
| `MEDULLA-SCM-R007` | **Path-scoped access control.** Stage: request boundary for `SubmitChangeset`, `ReadTree`, `ReadPathHistory`, `ReadBlame` and blob reads. `PathGrant{tenant, principal, prefix, read, write}` lives in new `crates/medulla-types/src/source_path_grant.rs` and is stored as a `:PathGrant` node. Resolution picks the longest prefix that matches on a path-segment boundary. No match means deny. Reads need `read`; a write needs `write` on every changed path. Caller: each method handler → `src/server/access/path_grant.rs::check`. The read-RLS gate extension is `MEDULLA-DURABLE-KERNEL-R870`. Depends on: `MEDULLA-SCM-R002`. | Test: `tests/test_scm_path_access.py::test_prefix_grant_filters_reads_and_refuses_writes` (L3).
