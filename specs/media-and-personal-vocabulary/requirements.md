# MEDULLA-MEDIA-VOCAB requirements

| ID | Requirement | Verification |
|---|---|---|
| `MEDULLA-MEDIA-VOCAB-R001` | **Shared media ontology.** Subsystem: ontology and packs, entry schema sources (`GraphSchemaSources`). `crates/medulla-core/ontology/media-v1.ttl` defines the media classes and properties and reuses core terms. The vocabulary covers work, series, season, episode, album, track, audiobook, podcast and game. It also covers ROM, library, library item, media file and playback session. It ends with download request, transfer, indexer, broadcast, viewer sample and transcript segment. Children `.1` to `.6` remain mandatory. Children `.100`, `.101` and `.102` are separate roots with their own acceptance and are not part of this rollup. No provider or export receipt is inferred. | Test: `crates/medulla-core/tests/media_vocab_a.rs` (L2) loads the module through the registered `core:media@1` source and passes for children `.1` to `.6`. |
| `MEDULLA-MEDIA-VOCAB-R001.1` | Add `mv:MediaWork` (⊑ `:CreativeWork`) with `mv:Film`, `mv:TelevisionSeries`, `mv:TelevisionSeason`, `mv:TelevisionEpisode`, `mv:MusicAlbum`, `mv:MusicTrack`, `mv:Audiobook`, `mv:PodcastShow`, `mv:PodcastEpisode`, `mv:Game` to media-v1.ttl. | Test: ontology load test asserts each class and its subClassOf path to `:CreativeWork`. |
| `MEDULLA-MEDIA-VOCAB-R001.2` | Add `mv:MediaLibrary`, `mv:LibraryItem` (links a work to a library, `mv:itemOf`, `mv:inLibrary`), `mv:MediaFile`, `mv:RomFile`, `mv:GamePlatform`, `mv:MusicArtist` (⊑ `:Organization`) to media-v1.ttl. | Test: ontology load test. |
| `MEDULLA-MEDIA-VOCAB-R001.3` | Add `mv:PlaybackSession` (⊑ `:Session`) with `mv:playedBy`, `mv:lastPlayedAt`, `mv:playCount`, `mv:playbackPositionSeconds`, and `mv:BroadcastStream` (⊑ `:Event`) with `mv:ViewerSample`, `mv:viewerCount`, `mv:sampledAt`, `mv:lastConnectAt`. | Test: ontology load test; domain and range check. |
| `MEDULLA-MEDIA-VOCAB-R001.4` | Add `mv:DownloadRequest` (states requested, wanted, grabbed, importing, imported, failed), `mv:DownloadTransfer`, `mv:GrabEvent`, `mv:MediaIndexer` and properties `mv:requestsWork`, `mv:transferOf`, `mv:grabbedFromIndexer`, `mv:transferState`, `mv:shareRatio`, `mv:lastActivityAt`, `mv:addedAt`. | Test: ontology load test. |

| `MEDULLA-MEDIA-VOCAB-R001.6` | Resolve the two name collisions: connector packages declare `:Episode` (TV) and `:Author` in the shared `:` namespace, while core-foundation-v1.ttl already defines `:Episode` (interaction unit) and software-v1.ttl `:Author` (git author). media-v1.ttl uses `mv:TelevisionEpisode`; cross-repo rows MEDULLA-MEDIA-VOCAB-R032 and MEDULLA-MEDIA-VOCAB-R033 move the connectors onto it. | Test: collision test lists every duplicate class IRI across ontology/*.ttl and the baseline names exactly the two connector aliases. |
| `MEDULLA-MEDIA-VOCAB-R002` | **Content-channel vocabulary: content-v1.ttl.** Subsystem: ontology and packs, entry schema sources. `crates/medulla-core/ontology/content-v1.ttl` defines feed, article, research paper, search query and result. | `MEDULLA-MEDIA-VOCAB-R003.1` | Declare the eight key properties as datatype correlation properties in media-v1.ttl and content-v1.ttl, without global inverse-functionality. Work identity keys include the class and provider namespace (Film and TelevisionSeries IDs cannot collide). Article identity uses its class-scoped normalized canonical URL. SearchResult uses source, query and native result key; SocialPost and EmailCampaign retain source-native IDs. Shared target URLs support joins without identifying the result, post, campaign and document as one entity. Repeated reads of the same source-native key upsert the same entity. | Test: equal URLs across Article, two queries' SearchResults and two SocialPosts preserve distinct records and their provenance; repeated same-key reads are idempotent; Film and TelevisionSeries with the same numeric provider ID remain distinct. |
