# EG-MEDIA-VOCAB requirements

| ID | Requirement | Verification |
|---|---|---|
| `EG-MEDIA-VOCAB-R001` | **Media and personal-content vocabulary: media-v1.ttl.** crates/eg-core/ontology/media-v1.ttl defines the shared media classes and properties (work, series, season, episode, album, track, audiobook, podcast, game and ROM, library, library item, media file, playback session, download request and transfer, indexer, broadcast, viewer sample, transcript segment) reusing existing core terms. Children R001.1 to R001.6. | Children LANDED. |
| `EG-MEDIA-VOCAB-R001.1` | Add `mv:MediaWork` (⊑ `:CreativeWork`) with `mv:Film`, `mv:TelevisionSeries`, `mv:TelevisionSeason`, `mv:TelevisionEpisode`, `mv:MusicAlbum`, `mv:MusicTrack`, `mv:Audiobook`, `mv:PodcastShow`, `mv:PodcastEpisode`, `mv:Game` to media-v1.ttl. | Test: ontology load test asserts each class and its subClassOf path to `:CreativeWork`. |
| `EG-MEDIA-VOCAB-R001.2` | Add `mv:MediaLibrary`, `mv:LibraryItem` (links a work to a library, `mv:itemOf`, `mv:inLibrary`), `mv:MediaFile`, `mv:RomFile`, `mv:GamePlatform`, `mv:MusicArtist` (⊑ `:Organization`) to media-v1.ttl. | Test: ontology load test. |
| `EG-MEDIA-VOCAB-R001.3` | Add `mv:PlaybackSession` (⊑ `:Session`) with `mv:playedBy`, `mv:lastPlayedAt`, `mv:playCount`, `mv:playbackPositionSeconds`, and `mv:BroadcastStream` (⊑ `:Event`) with `mv:ViewerSample`, `mv:viewerCount`, `mv:sampledAt`, `mv:lastConnectAt`. | Test: ontology load test; domain and range check. |
| `EG-MEDIA-VOCAB-R001.4` | Add `mv:DownloadRequest` (states requested, wanted, grabbed, importing, imported, failed), `mv:DownloadTransfer`, `mv:GrabEvent`, `mv:MediaIndexer` and properties `mv:requestsWork`, `mv:transferOf`, `mv:grabbedFromIndexer`, `mv:transferState`, `mv:shareRatio`, `mv:lastActivityAt`, `mv:addedAt`. | Test: ontology load test. |
| `EG-MEDIA-VOCAB-R001.5` | Add `mv:TranscriptSegment` (part of the existing `:Transcript` in personal-v1.ttl: reuse, do not redefine) with `mv:segmentStart`, `mv:segmentEnd`, `mv:noSpeechProb`, `mv:transcriptOf`. | Test: ontology load test asserts `:Transcript` is not redefined in media-v1.ttl. |
| `EG-MEDIA-VOCAB-R001.6` | Resolve the two name collisions: connector packages declare `:Episode` (TV) and `:Author` in the shared `:` namespace, while core-foundation-v1.ttl already defines `:Episode` (interaction unit) and software-v1.ttl `:Author` (git author). media-v1.ttl uses `mv:TelevisionEpisode`; cross-repo rows EG-MEDIA-VOCAB-R032 and EG-MEDIA-VOCAB-R033 move the connectors onto it. | Test: collision test lists every duplicate class IRI across ontology/*.ttl and the baseline names exactly the two connector aliases. |

| `EG-MEDIA-VOCAB-R003` | **Cross-source identity keys.** Shared join keys so independent connectors meet on one IRI: `mv:tmdbId`, `mv:tvdbId`, `mv:imdbId`, `mv:musicBrainzId`, `mv:isbn`, `mv:infoHash`, `cv:canonicalUrl`, `mv:contentSha256`. Children R003.1 to R003.3. | Children LANDED. |
| `EG-MEDIA-VOCAB-R003.1` | Declare the eight key properties as datatype correlation properties in media-v1.ttl and content-v1.ttl, without global inverse-functionality. Work identity keys include the class and provider namespace (Film and TelevisionSeries IDs cannot collide). Article identity uses its class-scoped normalized canonical URL. SearchResult uses source, query and native result key; SocialPost and EmailCampaign retain source-native IDs. Shared target URLs support joins without identifying the result, post, campaign and document as one entity. Repeated reads of the same source-native key upsert the same entity. | Test: equal URLs across Article, two queries' SearchResults and two SocialPosts preserve distinct records and their provenance; repeated same-key reads are idempotent; Film and TelevisionSeries with the same numeric provider ID remain distinct. |
| `EG-MEDIA-VOCAB-R003.2` | Specify normalisation (infoHash lower-case hex; canonicalUrl via scheme/host lower-case, tracking parameters and fragment stripped) as an `rdfs:comment` and a fixture table. | Test: normalisation fixture table passes. |
| `EG-MEDIA-VOCAB-R003.3` | Add the keyed-hash identity rule for email-derived joins (`cv:subscriberKey`), never storing the raw address. | Test: SHACL rejects a `cv:Subscriber` carrying a raw address property. |
