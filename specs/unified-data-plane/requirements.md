# EG-UNIFIED-DATA-PLANE requirements

| ID | Requirement | Verification |
|---|---|---|
| `EG-UNIFIED-DATA-PLANE-R001` | **Record attached-source and native-hosting architecture decisions.** EG documents, as approved architecture decision records, that attached third-party sources are the default integration path, that EG remains the single converged query engine, that native hosting is earned per application through a defined gate, the router's consistency contract, and the scope boundary of the pgrx companion. | Review of the merged architecture decision records confirms each decision is recorded and accepted. |
| `EG-UNIFIED-DATA-PLANE-R002` | **Unify attached-source registration into one owner-scoped registry (rollup).** EG provides a single owner-scoped attached-source registry that replaces the separate eg-plan ForeignSourceSpec::Sql, OBDA external_sources, and kernel mirror-target registrations, backed by a dialect-adapter contract covering the driver, SQL rendering, catalog reader, change capture, and type map. Credentials are resolved only by secret reference, and registration verifies the outbound target before persistence. This row is a rollup, split by code root into `EG-UNIFIED-DATA-PLANE-R002.1`, `.2` and `.3`; it is LANDED only when all three children are LANDED. | Integration tests show SQL, OBDA, change capture, and mirror paths all resolve through the same registered source, and registration of an unverified or cross-owner endpoint fails closed. |
| `EG-UNIFIED-DATA-PLANE-R002.1` | **Verify the outbound target before persisting a `ForeignSourceSpec::Sql` registration (producer path).** `ForeignSourceCatalog::register` runs the existing SSRF-sensitive destination gate (`eg_plan::federation_ssrf::check_sql_dsn`) against a `Sql` spec's DSN before the entry is inserted, so a registration naming a disallowed address never reaches the catalog. Depends on none (producer; `check_sql_dsn` and the owner-scoped catalog already exist). | A unit test registers a `Sql` spec whose DSN names a disallowed destination and confirms the catalog holds no entry for it afterward; a spec naming an allowed destination still registers. |
| `EG-UNIFIED-DATA-PLANE-R002.2` | **Verify the outbound target before persisting an OBDA `external_sources` registration (consumer path).** The OBDA table-source handler (`src/server/handlers/rdf/obda.rs::register_table_sources`) runs the same destination gate against each `ObdaExternalSource`'s DSN before registering it into the `ObdaSourceRegistry`, so OBDA registration fails closed exactly like the SQL federation path. Depends on `EG-UNIFIED-DATA-PLANE-R002.1` (reuses its verification call). | A unit test feeds `register_table_sources` an entry whose DSN names a disallowed destination and confirms the registry holds no source for it afterward; a disallowed entry does not block registering the other, allowed entries in the same call. |
| `EG-UNIFIED-DATA-PLANE-R002.3` | **Verify the outbound target before persisting a kernel mirror-target registration (sink path).** Once `EG-DURABLE-KERNEL-R024` lands a per-target mirror-sink registration (today `CdcHub` holds one process-global `ExternalCdcSink`, not a registry), that registration path runs the same destination gate before a mirror target is persisted. Depends on `EG-UNIFIED-DATA-PLANE-R002.1` and the same-repo `EG-DURABLE-KERNEL-R024` (status: BUILDING — the mirror-target registration concept does not exist yet, so this child has no code root to verify against today). | A unit test registers a mirror target whose destination is disallowed and confirms the sink registry holds no entry for it afterward. |
