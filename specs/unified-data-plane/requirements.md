| `MEDULLA-UNIFIED-DATA-PLANE-R001` | **Record attached-source and native-hosting decisions.** Subsystem: sources. The record is `docs/architecture/unified_data_plane_adr.md`. It holds five accepted decisions. First, attached sources are the default path and Medulla reads them as virtual graphs. Second, Medulla stays the one converged query engine. Third, Medulla keeps no synced second store. A copy is allowed only as the watermark-bound cache of MEDULLA-UNIFIED-DATA-PLANE-R038. Fourth, native hosting is earned per application through the gate of MEDULLA-UNIFIED-DATA-PLANE-R026. Fifth, the `pgrx` companion extension is a no-go. Mirror sinks and a shared relational platform are out of scope. The document is the only artifact; no runtime caller exists. Depends on: MEDULLA-UNIFIED-DATA-PLANE-R025 (retired), MEDULLA-UNIFIED-DATA-PLANE-R002.3 (retired). | Test: `tests/test_adr_unified_data_plane.py::test_adr_records_five_accepted_decisions` (L1) asserts five `## Decision` headings, the status `Accepted`, and the no-go wording. |
