| ID | Requirement | Verification |

| `EG-FINANCE-PRIMITIVES-R001` | **Cross-host BacktestRun digest and Pine parity for finance-core.** The BacktestRun content digest is canonical across supported host architectures by normalizing serialization, floating-point and timestamp inputs before hashing. A Pine companion script for the SuperTrend and ATR kernels produces the same signal transitions as the Rust implementation from a shared checked-in bar fixture and parameter version, and finance-specific classes are folded into one finance-v1 ontology with duplicate class definitions removed. | Independent builds on two architectures are compared for equal digests, and a parity fixture test asserts the Pine and Rust implementations produce identical signal transitions. |
| `EG-FINANCE-PRIMITIVES-R002` | **Rehome generic finance evaluation kernels into eg-numeric.** Rolling z-score, EWMA, information coefficient and ratio, effective sample size, Diebold-Mariano, deflated Sharpe, purged combinatorial cross-validation, probability of backtest overfitting, Brier, Kalman, Ornstein-Uhlenbeck, ADF and regime HMM calculations are owned by eg-numeric evaluation and calibration modules and are callable as UQL time-series functions. Finance-specific method wrappers are removed or remain only as thin documented aliases over the shared kernels, with callers migrated to the generic surface and generated method counts reconciled in one change. A regime derivation that requires an unbounded prefix refit declares a bound or refuses with a typed state-budget error rather than reporting an unverified result. Children R002.1 through R002.10 retain this entire contract and add causal, adaptive state-space filtering. | Unit tests cover each relocated kernel. A method-count reconciliation confirms that the generated inventory matches client bindings with no duplicate implementation. |
