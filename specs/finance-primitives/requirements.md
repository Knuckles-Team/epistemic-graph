| `EG-FINANCE-PRIMITIVES-R001` | **Cross-host BacktestRun digest and Pine parity for finance-core.** The BacktestRun content digest is canonical across supported host architectures. Serialization, floating-point and timestamp inputs are normalized before hashing. A Pine companion script covers the SuperTrend and ATR kernels. It produces the same signal transitions as the Rust implementation. Both read a shared committed bar fixture and parameter version. Finance-specific classes fold into one finance-v1 ontology. Duplicate class definitions are deleted. Production consumer: arbora `market.backtest_run` (ARBORA-DATA-MARKET-R003). | Independent builds on two architectures are compared for equal digests. A parity fixture test asserts the Pine and Rust implementations produce identical signal transitions. |
| `EG-FINANCE-PRIMITIVES-R002` | **Rehome generic finance evaluation kernels into eg-numeric.** Stage: numeric kernels.
